# AI Ассистент квалификации лидов для интегратора Битрикс24

Веб-приложение помогает менеджеру по продажам во время звонка: принимает транскрипт, анализирует клиентские реплики, показывает этап квалификации и предлагает следующий лучший вопрос.

## Возможности

- Двухколоночный интерфейс: транскрипт слева и рекомендации GPT справа.
- Разделение реплик менеджера и клиента.
- Обязательная карта квалификации: сфера бизнеса, сотрудники, задача внедрения, процессы, CRM, боль, бюджет, ЛПР, срочность и согласие на встречу.
- Анализ после каждой реплики клиента.
- Правила для ключевых фраз: Excel, порядок в заявках, неизвестный бюджет.
- Endpoint финализации, который формирует payload для будущей записи в сделку Битрикс24.
- Архитектура с fallback-логикой: без `OPENAI_API_KEY` работает локальный rule-based анализатор, с ключом используется OpenAI GPT.

## Быстрый старт

```bash
npm install
npm run dev
```

Frontend будет доступен на Vite-порту, backend — на `http://localhost:4000`.

## Переменные окружения backend

Создайте `.env` в корне или в окружении процесса:

```bash
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o-mini
PORT=4000
```

## API

### `POST /api/analyze`

Принимает массив реплик:

```json
{
  "transcript": [
    { "speaker": "manager", "text": "Добрый день!" },
    { "speaker": "client", "text": "У нас сейчас Excel" }
  ]
}
```

Возвращает анализ: этап, заполненные поля, пропуски, следующий вопрос, возражения, заметки, качество квалификации и вероятность встречи.

### `POST /api/finalize`

Формирует объект `bitrix24Payload` с полями сделки, которые можно передать в будущий адаптер Битрикс24 REST API.

## Будущие интеграции

Backend отделяет анализ разговора от транспорта, поэтому позже можно подключить:

- звонки Битрикс24;
- телефонию;
- real-time streaming транскрипции;
- запись звонков;
- автоматическое обновление карточки сделки через Bitrix24 REST API.
