# Leado Call Coach

MVP веб-приложения для аналитики звонков менеджера в реальном времени. Интерфейс показывает подсказки, выявленные возражения, тональность разговора, баланс речи менеджера и клиента, а также прогресс по этапам скрипта продаж.

## Возможности

- live-транскрипт звонка через Web Speech API в браузерах, где он доступен;
- ручной ввод реплик менеджера и клиента для тестирования без микрофона;
- демо-сценарий звонка с автоматическим появлением реплик;
- эвристическое обнаружение возражений по цене, срокам, конкурентам и ЛПР;
- расчет тональности, talk ratio, слов-паразитов и итогового call score;
- подсказка «что сказать сейчас» на основе текущего контекста звонка.

## Запуск

```bash
npm run start
```

После запуска откройте `http://localhost:4173`.

## Тесты

```bash
npm test
```

Тесты проверяют ключевые правила аналитики: возражения, тональность, talk ratio, определение спикера и next best action.
